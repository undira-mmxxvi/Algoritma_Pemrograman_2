# Tugas Project Python Kelompok — Studi Kasus: Klinik Hewan "PawCare"

> Jika studi kasus ini sudah dipakai kelompok lain, ganti konteksnya (bengkel motor, penyewaan kamera, kos-kosan, dst.) dengan tetap mempertahankan struktur kode.

Seluruh potongan kode memakai satu konteks: data pasien hewan, layanan, tarif, antrean, dan jam operasional klinik.
Jalankan dengan `python3 kode/NAMA_FILE.py`.

| Materi | File | Tujuan | Data | Proses utama | Data pengganti untuk demo |
|---|---|---|---|---|---|
| 1. Variabel & Tipe Data | `kode/01_variabel_tipe_data.py` | Menyimpan data satu pasien | nama, jenis, umur, berat, vaksin | Isi variabel, cetak, `type()` | "Bruno", "Anjing", 7, 12.8, False |
| 2. Operator | `kode/02_operator.py` | Hitung biaya & cek syarat | tarif, diskon, umur, berat | Aritmatika, perbandingan, logika, `in` | Ubah diskon/tarif, berat = 2.0 |
| 3. Percabangan | `kode/03_percabangan.py` | Kategori ukuran & dosis obat | berat | `if/elif/else`, bersarang | berat = 2.0 lalu 15 |
| 4. Perulangan | `kode/04_perulangan.py` | Daftar layanan, panggil antrean | layanan, tarif, antrean | `for`, `while`, `break`, `continue` | Tambah layanan, antrean = 5 |
| 5. Dictionary | `kode/05_dictionary.py` | Profil pasien & harga layanan | pasien, harga | Akses, ubah, tambah, hapus, `items()`, bersarang | Ubah harga, tambah pasien P003 |
| 6. List | `kode/06_list.py` | Kelola antrean | nama pasien, berat | `append/remove/insert/pop/sort`, slicing, comprehension | Ganti nama pasien/berat |
| 7. Tuple | `kode/07_tuple.py` | Data tetap klinik | jam, koordinat, hari libur | Unpacking, `count`, error immutable | Jam jadi ("07:30","20:00") |
